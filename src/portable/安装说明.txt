Code 启动器 0.1.1
支持 macOS 14 或更新版本，Apple 芯片和 Intel Mac。

安装
打开 DMG，将「Code 启动器」拖到「应用程序」。本包是临时签名的试用版，没有 Apple 公证或开发者证书。macOS 可能会拦截第一次打开。只从你信任的来源取得安装包，并先核对随附的 SHA-256。由你决定是否在「系统设置 → 隐私与安全性」为这个应用单独放行。

使用
1. 打开后会查找常见位置中的 Claude Code。也可手动选 claude 可执行文件。未安装时从官方说明安装。
2. 选择项目文件夹和网络模式。使用当前网络时沿用终端的网络。专用模式需要你已有的 HTTP/HTTPS CONNECT 代理，点眼睛展开设置，填写地址、端口、预期 IPv4 出口，以及可选账号和密码。用 HTTPS 代理可保护与代理服务器之间的认证信息。
3. 点「保存设置」可记住常用设置。勾选「记住代理密码」并保存时，密码保存到本机钥匙串。
4. 点「检查」。专用模式会通过代理检查实际出口和 Claude API 连通性，通过后等待「确认启动」。60 秒后需重查。首次认证由你通过 Claude 的正常流程完成。
5. 使用专用模式时保持启动器打开。点「断开通道」或复查失败会关闭本地代理里的会话连接并保留终端。重新检查并确认可恢复。若终端已经关闭，先「结束专用会话」，再启动新终端。

专用模式只管理由本启动器启动、且遵循代理设置的 HTTPS 请求。浏览器登录、插件、其他进程和忽略代理的软件需要各自的网络策略。本工具不会修改系统代理或提供线路。请使用你有权使用且符合当地要求的网络与账号。
